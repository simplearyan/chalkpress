## 1. Setup

Treat the points as vectors from the origin: $A = (1, 2)$ and $B = (2, 3)$. Scalar
multiplication scales every coordinate by $k$; addition and subtraction work
coordinatewise.

## 2. Scalar multiplication

$$2A = 2(1, 2) = (2, 4)$$
$$3B = 3(2, 3) = (6, 9)$$

## 3. Adding the vectors

$$A + B = (1 + 2,\ 2 + 3) = (3, 5)$$

## 4. Subtracting the vectors

$$A - B = (1 - 2,\ 2 - 3) = (-1, -1)$$

That completes the set:

$$\begin{aligned}
&2A = (2,4), \quad 3B = (6,9), \newline
&A + B = (3,5), \quad A - B = (-1,-1)
\end{aligned}$$

All four claims hold — option C.
