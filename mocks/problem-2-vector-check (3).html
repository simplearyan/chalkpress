Solving it

1

Scalar multiplication

To scale a vector by a number $k$, multiply every coordinate by $k$: $k(x, y) = (kx, ky)$.

$$2A = 2(1, 2) = (2, 4)$$ $$3B = 3(2, 3) = (6, 9)$$
2

Adding the vectors

Vector addition works coordinatewise — add the $x$'s together, then the $y$'s:

$$A + B = (1 + 2,\ 2 + 3) = (3, 5)$$
3

Subtracting the vectors

Subtraction is the same idea, just subtract instead of add:

$$A - B = (1 - 2,\ 2 - 3) = (-1, -1)$$
